## 部署准备与真实服务的区别

部署按钮及脚本、绑定描述、空白示例、14 份迁移、类型、隔离环境、故障恢复说明和线上验收步骤均在仓库中，见 [部署指南](../deployment.md)。发布脚本先迁移、迁移失败停止，不自动重建或清空数据库；全新 CLI 环境若尚无 D1，应先按指南创建／绑定或走按钮流程。

真实模型证据分别记录在 [S0](s0-local-and-real-ai.md)、[S4 会话](s4-persisted-chat.md)、[草稿](s4-ai-drafts.md)、[查账](s4-ledger-queries.md)，真实报价见 [S3](s3-reference-quotes.md)。这些经本地运行时调用真实服务，**没有证明云端网络、部署配额或实际 Access 策略**。真实脚本均需显式 opt-in，常规测试不使用 Key。本阶段补齐最初诊断脚本的 opt-in 防护，默认执行已验证只跳过。
