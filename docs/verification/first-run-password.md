# 首次打开网页设置密码

2026-10-21。本次追加需求：新用户完成部署后，直接在网站设置密码，不需要操作 Cloudflare Secret；AI 和微信稍后配置。

## 当前交付

- 根目录 `.env.example` 不再声明密码变量；中英文 README 的手动与 Agent 流程均改为部署后设置。
- 复用 Base UI 登录表单，支持密码确认、显示／隐藏、中英文、系统主题、手机和 PC、键盘操作及字段错误提示。
- 仅全新空白实例开放 `/api/auth/setup`。设置前拒绝业务接口，设置成功自动登录；密码单例写入与空白条件在同一 SQL 中检查，并发只能成功一次。
- 新增 `0019_web_password.sql`，不更新或删除业务数据。密码只保存随机盐和部署密钥参与的 PBKDF2 校验值；认证信息不进入 JSON／CSV 业务备份。
- Access 配置始终优先，部分配置不回退。原密码 Secret 兼容；恢复密码成功登录后不会重新启用旧网页密码或首次设置。

首次设置没有额外的部署者身份验证。部署者应先完成设置再分享网址；公开空白实例由最先成功设置密码者取得访问权。已有数据、服务配置或认证记录的实例不开放匿名认领。
