# 上期对比、消费频次与变化排行验收

2026-10-26，承接本地消费排行与图表联动改动。使用隔离的真实本地 D1/DO 与合成账目；没有访问、修改线上账本，没有提交、推送或部署。

## 功能

- 收入、支出、退款、净支出展示相对上期的金额变化与变化比例。上期为零时显示“新增”，持平时直接说明；上期净支出为负时只比较金额，不展示容易误解的比例。
- 新增消费频次与均价，展示本期笔数、平均每笔金额、上期值及变化。显式筛选收入或退款时改为对应笔数与均价。无记录的均价为“—”，不按零处理。
- 新增类目／标签变化排行，分为“增加最多”和“减少最多”，按金额变化幅度排序，包含本期新增和本期没有记录的分组。每项显示两期金额、笔数、均价，并可打开两期明细；明细继续按主币金额降序排列。
- 默认显示前 5 项变化，可展开全部并收起；切换变化方向时收起长列表。变化方向保存在地址中，刷新和从明细返回可恢复。
- 柱状图选中时段后，汇总、频次、均价、变化排行及原有金额排行一起联动。筛选类目、标签、原币和关键字等条件同时约束两期。
- 手机与 PC 沿用现有纸色、橙色、圆角和 Base UI 控件；保留中英、深色、键盘操作和手机图表选中列自动露出。

## 对比与金额口径

- 日：前一天。周：向前 7 天的相同星期范围；被报表边界截断的周也保持同样天数。月：完整月对比上个完整月，未完月对比上月相同日期进度，遇月末截断到有效日期。
- 连续完整自然月：对比紧邻的同数量完整月份。滚动／自定义范围：对比之前相同天数的区间。页面明确显示上期日期与对比方式；超出 1900 年下界时显示无法对比。
- 只统计正式账目，外币使用入账时确认的固定主币金额，不重新取汇率；退款按自身发生日独立计算，不倒扣原期间消费笔数或金额。
- 均价按主币金额除以对应笔数，使用整数最小货币单位精确四舍五入。多标签分组仍可重叠，分组金额不能相加作为总额。拒绝超出安全整数范围的汇总变化。
- 上期与本期汇总在同一个 D1 批次读取；不新增数据表、迁移或模型调用。对比参数按需开启，原有 AI 查账调用默认不增加对比数据。
